# Software Requirements Specification

## Objective

Develop a Single Owner E-Commerce Platform where only one administrator manages products and customers can place orders online.

## Functional Requirements

### Customer

* Register
* Login
* Browse Products
* Search Products
* Filter Products
* Add To Cart
* Manage Wishlist
* Place Orders
* Track Orders
* Review Products

### Admin

* Add Products
* Edit Products
* Delete Products
* Manage Inventory
* Manage Orders
* View Analytics

## Non Functional Requirements

* Responsive Design
* Secure Authentication
* Fast API Response
* Scalable Architecture
* Mobile Friendly

## Constraints

* Single Admin
* MERN Stack
* MongoDB Database
