# Single Owner E-Commerce Platform

A production-ready MERN Stack E-Commerce platform where a single owner manages products and customers can browse, purchase, and track orders.

## Features

### Customer

* Mobile Number Registration
* Mobile Number Login
* Product Search
* Product Filters
* Shopping Cart
* Wishlist
* Razorpay Payment
* Order Tracking
* Reviews & Ratings
* Dark Mode

### Admin

* Product Management
* Inventory Management
* Order Management
* Analytics Dashboard

## Tech Stack

### Frontend

* React
* Vite
* Redux Toolkit
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### Authentication

* JWT
* bcrypt

### Services

* Cloudinary
* Razorpay
